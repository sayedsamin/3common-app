# Feature modules

The home module demonstrates the file structure. Its commented files are deliberately inert placeholders requested for initial scaffolding; fill or remove them as pages are built. Export only real public functionality from index.ts.

For each new product area, create a named module with screens, components, and tests. Add api.ts, queries.ts, mutations.ts, schemas.ts, hooks.ts, store.ts, storage.ts, types.ts, and utils.ts only as applicable. Routes should re-export module screens through the module public API.

Auth and notifications are documented integration locations, not working features. Product areas such as events and people are examples in AGENTS.md, not assumed requirements.
